# Built-in music

The app reads `tracks.json` in this folder; each entry names an `.m4a` file here. To change the starter pack, replace the files and the entries (keep each `id` stable once released: saved stories refer to it).

Fields: `id` (lowercase letters, digits, hyphens), `file`, `title`, `artist`, `mood` (`upbeat`, `happy` or `nostalgic`), `durationSec`, `bpm`, `license`, `source`.
